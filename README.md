# Luuvish Tap

## How do I install these formulae?

`brew install luuvish/tap/<formula>`

Or `brew tap luuvish/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "luuvish/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
